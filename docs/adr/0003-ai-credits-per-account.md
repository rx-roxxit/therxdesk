# นำ AI credits กลับมา นับต่อ Account ต่อเดือนตาม Plan

upstream เคยมีเครดิต AI รายเดือนที่นับจาก token (commit `afc47e95`, 1 เครดิต = 150 token) แล้วลบออกในเดือน
กันยายน 2026 และ AGENTS.md ห้ามนำกลับ The RX Desk ตั้งใจเบี่ยงจากข้อนั้น: AI ใช้ API key ของเราเอง (OpenCode
ผ่าน provider `openai-compatible`) ค่าใช้จ่ายจึงตกที่เรา ถ้าไม่จำกัด ลูกค้าคนเดียวก็ทำให้ขาดทุนได้ เครดิตนับต่อ Account
(ไม่ใช่ต่อ Workspace แบบของเดิม เพราะ Workspace ไม่จำกัด) ได้ตามสัดส่วน GB ของ Plan (1,250 ต่อ GB) และเขียนเป็นโค้ด
RX Desk แยก ไม่ revert ของ upstream ลูกค้าไม่เห็นชื่อผู้ให้บริการหรือโมเดลที่ใช้ ทั้งใน UI, ข้อความ error และเอกสาร
(privacy เรียกว่า "ผู้ให้บริการ AI ภายนอก")

## Consequences

- ฟีเจอร์ที่เรียก AI เบื้องหลัง (ย่อแคปชันใน repurpose) ต้องไม่ล้มเมื่อเครดิตหมด
- ในโหมด self-host ไม่นับเครดิต
