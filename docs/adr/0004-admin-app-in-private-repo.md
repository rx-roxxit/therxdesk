# หน้าแอดมินเป็นแอปแยก ใน repo private บน admin.therxdesk.com

เฟส 1 ตัดสินว่าแอดมินใช้ CLI เท่านั้น เมื่อเปิดขายเป็น SaaS งานแอดมินมีมากเกินกว่าจะทำผ่าน CLI ได้: ดูลูกค้า, Plan,
subscription, ปรับ Quota และ AI credits, ระงับบัญชี, แก้ Catalog และสลับ Availability โดยไม่ต้องแก้โค้ด จึงทำหน้าแอดมิน
เป็น **แอปแยก ใน repo private ของเราเอง และ deploy แยก** ไม่ติดตั้งแพ็กเกจแอดมินไว้ในแอปหลัก เหตุผลคือแอปหลักเป็น
AGPL-3.0 ซึ่งลูกค้าใช้งานผ่านเครือข่าย โค้ดใดที่อยู่ในแอปหลักจึงต้องเปิด source ให้ลูกค้าด้วย หน้าแอดมินเป็นของเราเอง
ไม่จำเป็นต้องเปิด public และการแยกแอปยังทำให้ session ของแอดมินแยกจากลูกค้า และโค้ดแอดมินไม่ชนกับการ merge upstream

## Consequences

- แอปหลักต้องมีช่องทางให้แอปแอดมินอ่านและสั่งงาน (internal API หรือฐานข้อมูลร่วม ยังต้องตัดสิน) โดย logic อย่าง Quota,
  AI credits, Catalog และ Availability ยังอยู่ที่แอปหลัก
- ต้องยืนยันจาก AGPL §13 และ FAQ ของ FSF ว่าแอปที่แยกโปรแกรมแบบนี้ไม่ต้องเปิด source
- แพ็กเกจที่ใช้ในแอปแอดมิน (เช่น Filament) ไม่ใช่ dependency ของแอปหลัก
