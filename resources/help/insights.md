# Insights and analytics

Insights show how published posts performed on each network. Open Insights from the sidebar for every channel, or a
channel's own page for that channel alone.

## What is measured

Each network returns the figures it publishes: impressions, reach, likes, comments, shares, clicks and video views
where the network offers them. The app shows only the metrics that network reports, so two channels can show
different sets.

## Freshness

The app reads analytics in the background on a schedule. A figure can lag behind the network by a few hours. A post
published minutes ago may not have figures yet. Use the refresh action on a channel to read it now.

## Deleted posts

When a network confirms that a published post was deleted there, the app marks it deleted and stops refreshing it.
The historical figures stay. A post the app cannot check on a network stays as it was.

## Exports

An insights page can be exported as a file for the period and channels on screen. Exports contain the same figures
the page shows.
